# Diseño del primer modo: Co-op Wave Defense

La primera experiencia online conserva el ADN de Boomer Shooter: combate rápido, lectura clara y humor visual de cómic. No será un mapa plano para esconderse; cada zona ofrece una posición defensiva con un coste.

## Arena propuesta: La Planta de Reciclaje

- Patio central abierto: alto riesgo, buena visibilidad y pickups.
- Pasarela elevada: excelente para controlar oleadas, pero con dos accesos laterales.
- Sala de compactadoras: choke point útil para shotgun, con rutas de escape limitadas.
- Túnel de mantenimiento: rota las oleadas y evita que el equipo se quede en una sola esquina.
- Cuatro puntos de aparición: los enemigos nunca aparecen dentro de la zona segura del equipo.

## Reglas de oleadas

- La oleada empieza con una cuenta atrás breve y un aviso audiovisual.
- Cada oleada aumenta cantidad, velocidad y mezcla de enemigos.
- Cada tercera oleada incluye una variante élite o un mini-jefe.
- Los pickups aparecen en rutas expuestas, para que acampar tenga un coste.
- Si todo el equipo cae, se guardan estadísticas locales y se muestra el resultado.

## Cooperativo inicial

- 1–4 jugadores.
- El servidor decide spawns, daño, muertes y recompensas.
- Revivir requiere permanecer quieto unos segundos, creando decisiones de riesgo.
- No se añade economía, compras ni ventajas de pago en esta fase.
